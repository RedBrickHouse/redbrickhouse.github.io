메인 히어로 시안 v2

메인 페이지 첫 화면의 배경 영상을 내리고 그 자리를 대신할 히어로 시안들입니다. 모두 코드로 직접 그린 화면이라 생성형 이미지 느낌이 없습니다. 각 시안은 실제 메인 페이지 전체 흐름 안에서 보여지며, 좌측 하단 버튼으로 시안을 바로 전환할 수 있습니다. 마우스 반응·모션은 라이브에서 직접 확인해 주세요.

Kiro가 만든 영상 대체 히어로 · 풀스크린 비주얼 BEST

내려간 배경 영상을 대신하는 주인공급 풀스크린 히어로 비주얼을 Kiro(gpt-5.6-sol)에게 최고 퀄리티로 요청해 받았습니다. 순수 코드(Canvas/SVG/CSS, AI 이미지 아님)로 살아 움직이며, 문구는 전부 기존 그대로입니다. 정지 스크린샷엔 모션이 안 보이니 라이브에서 봐주세요.

R

잔광의 가마 Kiro

흑적색 공간에서 벽돌 가마의 열기처럼 천천히 호흡하는 광원 + 미세한 불씨·분진(Canvas). 불꽃을 그리지 않고 빛·온기·깊이로 "벽돌을 굽는 집"을 은유. 시네마틱·따뜻함.

 S

살아 있는 조적 Kiro

실제 벽돌의 비례·엇갈린 조적 리듬을 거대한 추상 건축 구조(SVG)로. 정밀한 원근·음영·빛의 주사·느린 조립 모션으로 "차곡차곡 쌓은 신뢰"를 직접 그림 없이 표현.
Kiro가 만든 배경 3종 · 기존 문구 그대로

위 R/S가 "풀스크린 영상 대체"라면, 아래 O/P/Q는 M안(기존 레이아웃)의 빈 배경만 은은하게 채운 버전입니다. 배경 레이어만 Kiro가 3종 생성.

O

러닝본드 베일 Kiro

엇갈려 쌓인 벽돌 줄눈을 반투명 건축 그리드 + 하중 수평선으로 추상화. 벽돌 형태를 그리지 않고 비례·구조감만 씀. 벽돌집 브랜드를 재질로 은유.

 P

소성광 오로라 Kiro

벽돌이 가마에서 구워질 때의 온기·빛을 흐릿한 저채도 컬러 필드로. 사물 없이 빛·깊이만으로 프리미엄 에디토리얼 무드.

 Q

퍼블리셔스 블루프린트 Kiro

정밀 도면 격자 + 기준축 + 측량 링. 집을 그리는 대신 건축 설계의 질서·정밀도만 차용해 전문적·현대적 인상.
참고 · 강점 문구 포함형 / 배경 없는 기본형
N

강점 전면 (문구 추가형)

1호 인디전문·산나비/고양이와스프·투자·언론을 문구로 넣은 안. 이번 피드백으로 보류(문구는 아래 뉴스가 대신함). 참고용.

 M

퍼블리셔 중심 (배경 없음)

O/P/Q의 베이스. 기존 문구 + 게임 포트폴리오만, 배경은 은은한 벽돌 그리드. 배경 비교용.
게임 커버형 (VOID DIVER가 주인공 — 퍼블리셔 사이트엔 부적합)
L

플래그십 커버

VOID DIVER 키아트를 화면 전체에 깐 시네마틱 안. 완성도는 높지만 한 게임이 주인공이라 퍼블리셔 사이트 성격과 맞지 않아 참고용으로만 남겨둡니다.
게임 쇼케이스 + 벽돌 브랜딩
K

게임이 사는 집 · 리서치 반영

퍼블리셔 사이트 6곳을 분석해 만든 웜다크 스플릿 안. 벽돌벽에 VOID DIVER featured, PROJECT B·O는 IN DEVELOPMENT 창으로 톤다운.

 J

게임이 사는 집 · 라이트

같은 컨셉의 밝은(크림) 배경 버전. K안과 비교용. 오른쪽 벽돌벽 위에 게임 카드를 갤러리처럼 배치.
모던 · 타이포/레이아웃 (일러스트 없음)
H

오로라 그라데이션 NEW

브랜드 레드빛 그라데이션이 화면 전체에서 부드럽게 흐르는 배경 위에 대형 타이포. 하단에는 라인업이 흐르는 티커. Stripe·Linear 계열의 깔끔하고 세련된 제품 랜딩 무드.

 I

스포트라이트 다크 NEW

차콜 배경에 미세한 그리드, 마우스를 따라 레드 조명이 움직입니다. 좌측 대형 타이포 + 우측 실제 게임 라인업 패널. 첫 화면에서 퍼블리셔라는 걸 바로 보여주는 프로덕트 랜딩 무드.
일러스트 계열
G

석양의 계곡

화면 전체가 레드빛 석양으로 타오르는 풀스크린 파랄락스 풍경. 마우스를 움직이면 층이 따라 움직입니다.

 E

밤의 벽돌집

깊은 밤, 불을 켜고 서 있는 벽돌집 시네마틱 일러스트. 브랜드 동화를 압축한 시그니처 안.

 F

낮의 벽돌집

E안의 낮 버전. 맑은 하늘 아래 초원 위 빨간 벽돌집. 밝고 친근한 무드.

 A

벽돌 쌓기

화면 아래에서 벽돌담이 한 장씩 쌓이는 애니메이션. 브랜드 스토리(정성으로 쌓은 벽돌집)를 그대로 화면에 옮긴 안.

 B

픽셀 아트

공식 CI 픽셀 벽돌집이 주인공. 흘러가는 픽셀 구름과 굴뚝 연기로 인디게임 감성을 살린 안.

 C

에디토리얼 타이포그래피

초대형 타이포와 하단 티커 스트립만으로 구성한 미니멀 안. 차분하고 신뢰감 있는 퍼블리셔 무드.

 D

게임 쇼케이스

VOID DIVER 등 실제 라인업 아트를 카드로 띄우는 스플릿 히어로. 첫 화면에서 게임부터 보여주는 안.
